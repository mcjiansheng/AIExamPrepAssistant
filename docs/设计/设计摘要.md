## 1. 已经定下来的设计

| 项 | 结论 | 依据 |
|---|---|---|
| 知识结构 | 章 → 主题 → 知识点。主题约 8 个知识点，只用于展示和排期；重点级别、掌握度等需要精确的信息记在知识点上 | E2、E2b、E3d |
| 重要度 | 由证据汇总：笔记、老师重点材料、作业、错题、往年卷、用户标记。每条证据带级别、考法和覆盖范围；范围外没提到的算“未知”，不降权；没有证据时标“依据有限” | v2 第 2.8 节；E9 |
| 考法 | 记忆、理解、计算与模拟、设计、证明、联动、大题。与级别分开，同时影响出题和计划 | v2 第 2.8 节 |
| 知识点关系 | 课程内增加前置、联动、应用、同一内容、易混。模型建议的关系要用户确认后才能用于出题 | v2 第 2.8 节 |
| 老师口头重点 | 两步：先映射到主题（宁可多），再选到知识点（多数表决）。边界上的知识点交给用户确认 | E3c、E3d |
| 复习题讲义 | 每道例题作为新知识点导入，级别记为强调；再找出它用到课件里的哪些方法。考试范围 = 课件 + 老师的重点材料 | E3c 补跑 |
| 计算题 | 先算后写：代码算出结果，模型只写叙述，数值和表格由代码填入 | E1，已采用 |
| 验证组 | 按题型选跑检查，删去 V2，V3 降为一次；裁决分硬失败、软失败、提示三档。单一模型的自检只能作为提示，不能保证题目正确 | 11-08 回归评测 |
| 批改 | 出题时同时生成评分点；客观题由代码判分，主观题默认对照评分点自评，模型评分可选 | 推断，E5 待做 |
| 每道题附带 | 出处页码和原页截图、验证提示、一键报错 | 已有结论 |
| 课程之间的差异 | 每门课一份课程画像；流程固定，留出扩展点（资料类型、知识类型、考法词表、题型、验证器）。扩展只接受声明式数据，由用户确认生效；代码类扩展只来自团队。不采用 agent 运行时自己写插件 | v2 第 2.9 节；E11 待做 |
| 三级分工 | 个人层是核心；校内层增加课程画像；跨校层不再共享课程内容，改为共享扩展模板。本期跨校层只写设计 | v2 第 2.9 节 |
| 资料中的注入 | 模型区分“资料”和“指令”只算第一层；处理资料时没有危险工具，画像和扩展只能经用户确认变更 | v2 第 2.9 节 |
