# 09 · 核心流程细节

状态：v1 细节设计，2026-11-25（PST）。把 00–08 里的每个核心流程落到“状态、触发、规则、失败”这一层，前端和服务端都按本文实现。字段与接口见 `docs/接口合同/api-v1.md`；规则以本文为准，字段以合同为准。AI 流程内部（出题、核对、重点映射）仍以 `../设计修订v2.md` 为准。

每节按同一顺序写：入口 → 步骤 → 状态 → 失败。可调的数字集中在第 11 节。

## 2. 首次使用

1. **欢迎页**：“开始使用” → 登录；“先看看示例” → 访客会话（`POST /auth/guest`），进今天页，只有示例课程，顶部细条“示例模式 · 登录”。
2. **登录后**：`onboarding.ai` 为空 → 引导第 1 步连接 AI；`onboarding.course` 为空 → 第 2 步建课。两步都能跳过，跳过记 `skipped`，之后不再自动出现。
3. **访客要保存自己的东西**（建课、上传、连接 AI）：服务端返回 403 `login_required` → 客户端弹出登录层，登录成功后重发原操作。示例课程里的进度不迁移。

## 3. 连接 AI

入口：首次引导、`我的 → AI 模型`、任何需要 AI 的操作当场。三处是同一个三步流程（04 第 2.1 节）。

| 步 | 用户 | 服务端 | 失败 |
|---|---|---|---|
| 1 选服务商 | 点预设卡片，或“自定义（OpenAI 兼容）” | — | — |
| 2 填密钥 | 粘贴密钥（自定义还要地址、模型） | `POST /me/providers` 存密钥，返回末 4 位 | 格式明显不对时当场提示 |
| 3 检查 | 看逐项打勾 | `POST /me/providers/{id}/check`：`connect` → `models` → `json` → `tools` → `vision` | 前两项失败：回到第 2 步，显示服务商原因；后三项失败只影响能力，照常保存 |

- 检查完成：按预设选好默认模型；`vision` 为 ✕ 时那一行给“添加看图模型”。
- **当场连接**：AI 操作返回 409 `ai_required` → 客户端弹出连接层；连接成功后用同一个幂等键自动重发原请求；用户关掉连接层 → 原操作取消，不再提示错误。
- **后台任务没有连接时不报错**：资料进入 `waiting_ai`，课程显示“等待连接 AI 后整理”；连接成功后服务端自动开始。

## 4. 新建课程与整理

一屏一问，每一步立即保存，任何一步都可以“稍后再说”（跳到下一步）。

| 步 | 用户 | 服务端 | 离开引导后 |
|---|---|---|---|
| 1 课程与考试日期 | 名称；日期或“还不确定” | `POST /courses`，课程立即存在 | 课程已在列表里 |
| 2 资料 | 选文件 / 拖入 / 拍照，可多份 | 上传后开始整理（ingest Job），客户端不等 | 课程主页“下一步”出现“添加资料” |
| 3 老师说的重点 | 粘贴或拍照原话 | `POST /courses/{cid}/focus/fragments`；知识点还没出来时先存原话，出来后自动分析 | — |
| 4 考试形式 | 第 3 步识别出题型时预填，确认或修改 | `PUT /courses/{cid}/exam-format` | 用默认形式，标“默认” |
| 5 每天给这门课的时间 | 滑块；默认“自动分配” | `PATCH /courses/{cid}` `daily_cap_min`（null = 自动） | 自动分配 |
| 6 完成 | 进入课程主页（整理中） | 整理完成 → 通知 + 地图点亮 + 日程重算 | — |

- **整理阶段**（`stage` 文案）：读取资料 → 抽取知识点 → 分组 → 分析老师重点 → 排进日程。地图格子随知识点出现逐个亮起（M5）。
- **自动判断**（重复版本、资料角色）直接生效，资料行显示一行结果 + “改”；改了之后服务端重算受影响的部分。
- **失败**：单份资料失败不影响其他资料；部分页读不出 → 资料仍为 `ready`，一行“第 12、13 页没读出来 · 重新上传”。

## 5. 今天与日程

### 5.1 今日任务的计算（服务端，代码规则，不交给模型）

1. **可用时间 T**：今天的临时值（`PATCH /today`）或设置里的每日时间。
2. **课程份额**：`need_c` = 该课未掌握知识点的级别权重之和（强调与待确认 4、提及 2.5、未提及 1、不考 0）；紧迫度 `U_c` = 4（离考试 ≤ 2 天）、`1 + 6 / d`（d 为离考试的天数）、0.5（没有考试日期）。分到 `T × U_c·need_c / Σ U·need`，不超过课程的每日上限，至少 15 分钟，按 5 分钟取整。考试已过的课程不再排。
3. **课内顺序**：到期复习 → 昨天没做完的（标“顺延”）→ 计划里的新知识点（先学后练）→ 快练补满。
4. **任务粒度**：学习任务含同一主题的 1–3 个知识点，时长按主题时长分摊，下限 5 分钟；快练 5 题约 10 分钟；复习每题约 1.5 分钟；模拟卷用考试形式的时长，只在考前 7 天内排、每门课最多 3 天一次。
5. **理由**：每个任务带一句 `reason`（“老师强调 · 还没学”），点开任务菜单才显示。
6. **重算时机**：每天第一次打开、改可用时间、作答改变掌握度后（只重排今天未开始的任务）、助手或用户挪动、资料整理完成。`pinned` 的任务不被重算移动。

### 5.2 任务的开始与完成

| 类型 `kind` | 点开 | 自动完成 |
|---|---|---|
| `learn` | 第一个还没“懂了”的知识点页，页头显示“任务 2/3” | 任务里的知识点都点过“懂了”，或小测都做完 |
| `practice` | 新建本课快练；已关联练习时继续它 | 练习完成 |
| `review` | 新建到期复习 | 练习完成 |
| `mock` | 先显示题量、时长和用量估算，确认后新建模拟卷 | 交卷 |
| `mistakes` | 本课错题重做 | 练习完成 |

手动勾选任何任务都算完成。勾选、跳过、挪动都直接执行，可撤销。

### 5.3 顺延与日程页

- 昨天没完成的任务在今天第一次计算时挪到今天，带 `moved_from`；今天页顶部一行“昨天有 2 项没做完，已排进今天”，当天只出现一次。
- 日程页拖动任务 = 改日期，并自动 `pinned`；手机上长按 → “挪到……”。“按现在的情况重排”保留 `pinned` 的任务。

## 6. 学习一个知识点

- **打开**：客户端上报学习位置（`PUT /me/resume`），供任何设备的“继续”卡片使用。
- **内容**：讲解分段（每段带出处）、老师原话、怎么考、课件原页、小测 2–3 题。
- **懂了**：`new` → `learned`（只是显示状态，不算掌握）；`shaky` / `mastered` 不变。服务端返回下一个知识点（任务内的下一个，否则同主题的下一个）；任务里最后一个点完 → 任务完成，回到今天页时播 M2。
- **AI 动作**：讲简单点、举个例子、考考我、和……有什么区别 → 发到本课线程（带 `command`），结果是讲解卡或题目卡，显示在讲解区下方，同时出现在线程里。没连接 AI 时走第 3 节。
- 小测作答和练习一样影响掌握度。

## 7. 练习与作答

### 7.1 练习种类

| `kind` | 默认题数 | 选题 |
|---|---|---|
| `quick` | 5 | 不稳和到期的优先，再补强调且未掌握的；先用已核对的题库题，不够再现出 |
| `kp` | 3 | 指定知识点 |
| `review` | 到期题数（最多 20） | 到期的题 |
| `mistakes` | 选中的错题或全部（最多 10） | 原题重做；“同类题”是同一知识点现出一道 |
| `mock` | 按考试形式 | 按题型配比，覆盖强调的知识点，计时 |

### 7.2 先出后核

- 新建练习立即返回（`preparing`），题位是 `pending`；有一道 `ready` 就进入 `active`。客户端第一道能做就开始作答，不等全部出完。
- `ready` + `check: checking`：可以作答，标“核对中”。
- 核对通过 → `passed`。发现硬错误：未作答 → 原位换成新题（`version` + 1，客户端提示“这道题换成了新题”）；已作答 → `flagged`，不计分，解析里写明原因。
- 出题失败的题位 → `failed`（“没出成”），可以“继续出题”（重试 Job）；完成练习时去掉，不计入总分。
- 核对用量用完 → `unchecked`，标“未经核对”。

### 7.3 作答与判分

- 同一道题在一次练习里只答一次；在新的练习里可以再答（错题重做）。
- `single`、`fill`：代码判分，立即反馈（M3）。
- `calc`：代码比较最终答案 → `needs_self_grade`，最终答案对时评分点默认满分，用户可以下调。
- `short`、`proof`、`design`：`needs_self_grade`；可以不写字，直接对照评分点自评。
- 部分得分按评分点分值的一半计。

### 7.4 提示阶梯

- 第 1 级方向，第 2 级关键一步，第 3 级完整解析。点第 3 级前确认一句“会记为看过答案”；之后 `peeked = true`，答对也不计入掌握。用户说“直接告诉我答案”同样处理。
- 提示没通过答案泄露检查时，换成通用提示（v0.1 已实现）。
- **主动提示**：同一题停留 3 分钟，或同一知识点连续答错 2 次，“求助”按钮旁浮出一句“要不要提示？”。每题一次，设置里可以关。

### 7.5 报错、完成、错题本

- **报错**：选类型 + 可选备注 → 该题 `hidden`，不计分，从本次练习移除并跳到下一题；后台复查按 v2 第 3.6 节。
- **完成**：还有题没做时确认一次（“还有 2 道没做，完成吗？”），没做的不计分。模拟卷时间到 → 弹“时间到”：交卷（主按钮）/ 继续做（不再计时）。
- **错题本**：答错或部分得分的题进错题本；之后在两次不同的练习里做对 → 自动移出；也可以手动移出（可撤销）。

## 8. 掌握度与到期复习

### 8.1 状态规则（v2 第 2.3 节 + “学过”）

| 事件 | 结果 |
|---|---|
| 点“懂了” | `new` → `learned` |
| 做错，或部分得分 | → `shaky` |
| 在两道不同的题上做对（不含看过答案、被标记有问题、被报错的题） | → `mastered` |
| 做对一次，且用户标记“已掌握” | → `mastered` |
| `mastered` 后做错 | → `shaky` |

- 状态由事件算出；主题和章节的掌握度由知识点汇总。
- **准备度** = 已掌握的重点知识点 / 重点知识点总数。重点 = 强调、待确认、提及；一门课没有任何重点时，用全部未排除的知识点。

### 8.2 到期复习（FSRS 思路的简化版）

- 每个知识点存稳定度 S（天）和到期日。第一次做对 S = 2，做错 S = 0.5。之后做对 S × 2.5（用过提示或部分得分 × 1.5），做错 S = max(0.5, S × 0.5)。
- 间隔 = S × 强度系数（轻松 1.3、标准 1.0、冲刺 0.7），再压缩到不超过 max(1, ⌊离考试天数 / 2⌋)，保证考前至少再复习一次。
- 到期日 ≤ 今天的题进入到期复习。

## 9. 助手

1. **线程**：每门课建课时自动建一条线程，另有一条全局线程；用户可以新建。页面上点“问助手”进入当前课程的线程；不在课程内时进全局线程。
2. **一轮对话**：客户端发消息（带上下文）→ 服务端流式返回：正文片段、工具行、卡片、记忆 → `done` 或 `error`。
3. **上下文**：`{ route, course_id, kp_id, session_id, question_id, material_id, page, selection }`，输入框上方显示为标签，点掉的项本条消息不带。
4. **权限落到卡片**（03 第 3 节）：只读 → 折叠的工具行；直接执行 → 改动卡（撤销）；先提议 → 提议卡（确认 / 取消）；预计用量超过阈值 → 提议卡带估算。
5. **页面联动**：卡片带 `affects`（今天、日程、课程、地图、资料、重点、练习、设置）；客户端刷新这些区域，并把页面上被改的地方高亮一次（M7）。
6. **撤销**：页面操作和改动卡共用一套撤销。撤销在之后的改动碰到同一对象之前都有效，最长 24 小时；失效时卡片显示“已无法撤销”。
7. **多步任务**：任务卡列出步骤；超过 30 秒的步骤转成后台 Job，可以离开、可以停止，完成后通知。
8. **失败**：没连接 → 连接卡，连接后自动重发；密钥失效或余额不足 → 卡里写原因 + 去更新；网络中断 → 消息标“未发送 · 重发”；工具失败 → 说哪一步、为什么 + 重试。已经执行的动作保留。

## 10. 资料、老师重点、通知

- **资料**：支持 PDF、PPTX、DOCX、TXT、Markdown、图片（PNG、JPG、HEIC）；单个文件不超过 50 MB，一次最多 20 个。照片和扫描页自动走内置文字识别。电脑上“用手机拍”显示二维码，手机扫码后拍照直接传到这门课。删除前的确认写明影响：“会删掉 42 个知识点和 6 道题”。被新版本取代的资料折叠显示。
- **老师重点**：原话按句切成片段 → 两步映射（v2）→ 每个片段对应的知识点，分 `sure`（实线）和 `maybe`（虚线，“可能也包括”，点一下选入或移除，可撤销）。同一知识点既被说“不考”又被说“强调”时显示一行“两句说法不一致 · 选一个”，不选按强调处理。
- **通知**：整理完成、出题完成、考试临近（考前 3 天、1 天）、每日提醒、后台任务失败。站内通知列表 + 浏览器通知（用户授权后）；在“提醒”里逐项开关。

## 11. 默认值与阈值

| 项 | 值 |
|---|---|
| 每日可用时间 | 120 分钟（30–600，可在今天页临时改） |
| 快练题数 | 5 |
| 撤销条 | 显示 5 秒；撤销有效期见第 9 节 |
| 单次确认阈值 | 预计 20,000 token |
| 主动提示 | 同一题停留 3 分钟，或同一知识点连续答错 2 次 |
| 错题自动移出 | 两次不同的练习里做对 |
| 验证码 | 60 秒后可重发；同一号码连续错 5 次锁 10 分钟 |
| 上传 | 单个文件 50 MB，一次 20 个 |
| 访问令牌 / 刷新令牌 | 15 分钟 / 30 天 |
| 注销冷静期 | 7 天 |
