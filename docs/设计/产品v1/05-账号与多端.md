# 05 · 账号与多端

## 1. 账号模型

| 对象 | 说明 |
|---|---|
| 用户 | 一个人一个用户；主身份是手机号 |
| 登录方式（身份） | 手机号；华为账号（UnionID）。两者通过手机号关联到同一用户 |
| 设备 | 每台登录过的设备一条记录：类型（手机 / 平板 / 电脑 / 浏览器）、名称、最近使用时间 |
| 会话 | 短期访问令牌 + 长期刷新令牌，按设备签发，可单独吊销 |

本版要求：手机号验证码登录完整实现（短信发送可先接测试通道，验证码在开发环境打印到日志）；华为账号一键登录**只做界面和接口设计**，服务端留好换取手机号的接口，客户端接假实现。

原因：华为账号一键登录需要在 AppGallery Connect 配置应用的 Client ID、申请“一键登录”权限并通过审批，且官方说明暂不支持在模拟器上调试。我们目前只有模拟器。

## 2. 登录界面

### 2.1 鸿蒙端（手机、平板、电脑）

按华为账号登录的界面规范设计，否则上架审核不过：

- 应用图标与名称。
- 匿名手机号（如 138****0000），下方固定文字“华为账号绑定号码”。
- 华为账号一键登录按钮（使用系统提供的登录按钮组件）。
- 协议勾选：《华为账号用户认证协议》《用户协议》《隐私政策》，默认不勾选；未勾选点登录时，提示勾选而不是直接拒绝。
- “其他手机号登录”入口 → 手机号验证码页。

流程：客户端拿到授权码 → 发给服务端 → 服务端向华为账号服务换取手机号和 UnionID → 按手机号查找或创建用户 → 签发会话。

### 2.2 Web / 电脑浏览器

- 手机号 + 验证码（新号码自动注册）。
- **扫码登录**：页面显示二维码，用已登录的手机端扫一扫，手机上确认后电脑登录。这是最自然的多端协作入口，也省去电脑上再收验证码。
- 验证码规则：60 秒后可重发；同一号码连续 5 次输错锁定 10 分钟；提示用原因说清楚（“验证码错误，还可以试 3 次”）。

### 2.3 登录之后

首次登录进入首次引导：连接 AI（04）→ 建第一门课（06），每一步都可跳过，跳过后进入带示例课程的今天页。

## 3. 同步

- **服务端是唯一数据源。** 客户端缓存最近的数据用于离线查看：今天、课程结构、已出好的题、讲解、自己的笔记。
- **离线也能做的事**：查看缓存内容、作答已缓存的题、勾选任务、写笔记。这些操作记成带客户端时间的事件，联网后按顺序提交。
- **冲突规则**：
  - 作答：每题以先提交的为准（与 v0 规则一致：每题只答一次）。
  - 任务勾选、笔记、设置：以最后修改为准。
  - 日程调整：服务端重新计算，客户端以服务端结果为准，并在今天页说明“已按另一台设备上的调整更新”。
- **实时更新**：服务端为每个用户提供一条事件流（SSE），推送任务进度（整理、出题）、其他设备上的改动、通知。取代 v0 的轮询。

## 4. 多设备协作

“每种设备做适合它的事”（02 第 5 节）之外，还有这些跨设备的协作：

| 能力 | 做法 | 阶段 |
|---|---|---|
| 扫码登录 | 第 2.2 节 | P0 |
| 继续上次 | 今天页“继续”卡片显示任何设备上最后一次的学习位置（知识点页、做到第几题），点开继续 | P0 |
| 用手机拍照传到电脑 | 电脑上“添加资料 → 用手机拍”显示二维码，手机扫码后直接打开相机，拍完传到这门课。鸿蒙原生版改用系统的跨设备拍照能力 | P0（二维码）/ P2（原生） |
| 应用接续 | 手机上看到一半的知识点页、做到一半的练习，在平板上点接续图标继续。接续数据：页面、位置、未提交的作答草稿 | P2 |
| 服务卡片 | 见第 5 节 | P2 |
| 小艺意图 | 见第 6 节 | P2 |

## 5. 服务卡片（P2，现在定设计）

鸿蒙卡片有 1×2、2×2、2×4、4×4 四种尺寸，每种的信息量不同：

| 尺寸 | 内容 | 点击 |
|---|---|---|
| 1×2 | 最近一门考试：课程名 + 倒计时天数 | 打开该课程 |
| 2×2 | 倒计时 + 今日进度环（完成几项 / 共几项） | 打开今天 |
| 2×4 | 今日前三项任务（课程色点 + 名称 + 时长）+ 进度 | 点任务直接开始 |
| 4×4 | 一门课的知识点地图缩略 + 今日任务 | 打开课程主页 |

卡片每天早上和每完成一项任务时刷新。视觉与应用内一致（07），不用额外插画。

## 6. 小艺意图（P2，现在定清单）

通过 HarmonyOS 意图框架把高频动作注册给系统，用户可以对小艺说，或在系统搜索里直达：

| 意图 | 说法示例 | 打开 |
|---|---|---|
| 今天复习什么 | “今天要复习什么” | 今天页 |
| 开始快练 | “出 5 道操作系统的题” | 快练（指定课程） |
| 考试倒计时 | “离高数考试还有几天” | 系统卡片式回答 + 课程主页 |
| 继续上次 | “继续复习” | 上次的位置 |
| 添加资料 | “把这张照片加到操作系统” | 资料上传 |

## 7. 提醒与通知

| 类型 | 默认 | 说明 |
|---|---|---|
| 每日学习提醒 | 开，20:00 | 时间可改；内容为今天剩余任务数 |
| 考试临近 | 开 | 考前 3 天、前 1 天 |
| 后台任务完成 | 开 | 资料整理完、出题完、多步任务完成 |
| 助手主动提示 | 开 | 只在应用内，不推送 |

Web 用浏览器通知（用户授权后）和站内通知；鸿蒙原生用系统通知和提醒代理。

## 8. 我的 → 账号相关页面

- **个人信息**：昵称、头像；学校、专业（可选，为下一版课程共享预留，现在只存不用）。
- **账号与安全**：手机号（可更换，需验证新号）、华为账号绑定状态、登录设备列表（可逐台退出）、退出登录。
- **数据**：导出全部数据（课程、资料原件、笔记、作答记录、对话，打包下载）；注销账号（确认后进入 7 天冷静期，期间登录可恢复；到期后删除全部数据，包括模型密钥）。

## 9. 合规要点

- 用户协议、隐私政策、个人信息收集清单、第三方共享清单（模型服务商由用户自己选择，清单里说明这一点）。
- 资料处理说明：课件、照片、对话会发送给用户选择的模型服务商；平台不用用户资料训练模型；用户可以随时删除。
- 首次启动不强制登录即可查看示例课程；需要保存数据时再登录。
- 注销路径在设置里不超过三层。
