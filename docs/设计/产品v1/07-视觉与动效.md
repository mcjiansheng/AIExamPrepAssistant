# 07 · 视觉与动效

## 1. 方向

**鸿蒙原生的质感，加一个只属于我们的标志：知识点地图。**

- 成熟的原生应用遵循系统规范：系统字体、系统色、系统图标风格、系统的圆角和间距。照这个做，Web 版看起来就是一个“鸿蒙应用”，转 ArkUI 时几乎一一对应。
- 产品个性不靠渐变、插画和花哨配色，而靠三样东西：**知识点地图**（掌握度的可视化）、**大号数字**（倒计时、准备度、得分）、**回应操作的动效**。
- 去掉 v0 的“试卷与荧光笔”主题：衬线标题、黄色荧光笔、红笔绿笔都不再使用。

下文数值是设计基准，鸿蒙端以系统资源为准，Web 端按本表实现并集中在 token 文件里（08）。

### 2.2 掌握度色（产品标志色）

只用来表示掌握度，任何装饰都不用它们。

| 状态 | 颜色 | 形状（不依赖颜色也能区分） |
|---|---|---|
| 未学 | 描边 `#C5CBD3` | 空心格 |
| 学过（点过“懂了”，未经练习验证） | 描边 `#C5CBD3` + 中心点 | 空心格带点 |
| 不稳 | `#F2A93B` | 下半格填充 |
| 掌握 | `#24A26B` | 整格填充 |

附加标记：老师强调——格子外 2px 深色描边环（`text.primary`）；不考——虚线描边，整体 35% 透明度；当前所在——`accent` 色描边环。

### 2.3 课程色

区分课程用（今天页的色条、倒计时胶囊、日程色块）。八个色相，避开掌握度的绿和琥珀：

`#3A6FF7` 蓝、`#7B5CF0` 紫、`#E0559A` 粉、`#1AA6B7` 青、`#5E6AD2` 靛、`#D9734E` 赭、`#8C6E54` 褐、`#5B7083` 石板。新建课程时按顺序分配，可在课程设置里改。

| `bg.surface` | `#1C1C1E` |
| `bg.sunken` | `#2C2C2E` |

## 3. 字体

全站 **HarmonyOS Sans SC** 一种字体，靠字号和字重分层；数字用等宽数字（`font-variant-numeric: tabular-nums`）。Web 端随前端发布字体子集文件；加载完成前用系统无衬线字体兜底。

| 级别 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 大数字 | 40 / 48 | Medium | 倒计时、准备度、得分 |
| 标题 1 | 24 / 32 | Bold | 页面标题 |
| 标题 2 | 20 / 28 | Medium | 区块标题 |
| 标题 3 | 16 / 22 | Medium | 卡片标题、列表主文字 |
| 正文 | 16 / 26 | Regular | 讲解、题干、对话 |
| 正文小 | 14 / 20 | Regular | 次要信息 |
| 注释 | 12 / 16 | Regular | 元信息、出处 |
| 标签 | 10 / 14 | Medium | 角标 |

讲解和题干的行宽不超过 38 个汉字；大屏上讲解区限宽，多出来的空间给原页和助手，不拉长行。

## 4. 布局、间距、圆角

- **间距**：4 的倍数：4、8、12、16、24、32、48。
- **页面边距**：sm 16、md 24、lg 32。
- **栅格**：sm 4 列、md 8 列、lg 12 列，列间距 12 / 16 / 24。
- **圆角按层级**：分组容器 20；列表项、卡片 16；输入框 12；标签 8；知识点格子为边长的 25%。按钮为胶囊形。
- **层次**：页面底色与白色容器的对比分层，**卡片不加阴影**。只有浮在内容上的东西有阴影：助手弹层、菜单、撤销条、手机底部输入条（`0 8px 24px rgba(0,0,0,0.10)`）。
- **不要什么都装进卡片**：大屏上的分栏用留白和细分隔线，不用一张张卡片拼。

**图标**：一套 24×24 网格、1.5 线宽、圆角端点的线性图标，风格对齐鸿蒙 HM Symbol。Web 端自绘 SVG 或选一个风格接近的开源图标集（新增依赖需确认）；维护一张“Web 图标名 ↔ HM Symbol 名”的对照表。禁止用字符（✕ ⋯ ＋）和表情当图标。

## 6. 知识点地图

全产品的视觉主线。

- **结构**：一门课的知识点按章节分块，块内按知识点顺序从左到右、从上到下排成方格；块上方是章节名和“已掌握 / 总数”。
- **尺寸**：格子边长 sm 14、md 16、lg 18，间距 4；缩略图（课程卡、服务卡片）边长 6–8，间距 2，不显示章节名。
- **状态**：第 2.2 节。
- **交互**：按下或悬停显示知识点名和状态；点击进知识点页。缩略图整体可点，不响应单格。
- **无障碍**：每格有完整的读屏文字（“银行家算法，不稳，老师强调”）；章节块可键盘逐格移动。
- **空与整理中**：骨架格子，随整理进度逐个出现（M5）。

## 7. 动效

原则：**只在状态变化时动**，让用户看清“变了什么”；时长短，交互类用弹簧；尊重“减少动态效果”。全产品只有一处进场动画（欢迎页）。

### 7.1 动效 token

| Token | 值 | ArkUI 对应 |
|---|---|---|
| `dur.press` | 100ms | `animation({ duration: 100 })` |
| `dur.short` | 200ms | |
| `dur.medium` | 300ms | |
| `dur.long` | 450ms（页面、共享元素） | |
| `ease.standard` | `cubic-bezier(0.2, 0, 0, 1)` | `curves.cubicBezierCurve(0.2, 0, 0, 1)` |
| `spring.default` | 响应 0.35s，阻尼 0.85 | `curves.springMotion(0.35, 0.85)` |
| `spring.bouncy` | 响应 0.4s，阻尼 0.6 | `curves.springMotion(0.4, 0.6)` |

### 7.2 关键动效

| 编号 | 时刻 | 规格 | ArkUI |
|---|---|---|---|
| M1 | 卡片进详情（课程卡 → 课程主页，任务卡 → 学习页） | 卡片位置和尺寸过渡到目标页头，`dur.long` + `ease.standard`；返回时反向 | `geometryTransition` |
| M2 | 勾掉任务 | 勾的描边画出 200ms → 卡片高度收起、移入“已完成” 300ms → 进度环增长 `spring.default` | `animateTo` |
| M3 | 答题反馈 | 答对：选项放大到 1.04 再回弹（`spring.bouncy`）+ 变绿；答错：水平位移 ±4px 两次 200ms + 变红；地图对应格子同时变色 | 属性动画 |
| M4 | 掌握度揭晓（结果页、从结果回到课程） | 变化的格子依次变色：每格放大到 1.25 回弹，间隔 40ms，总时长不超过 1.2s；得分数字从 0 滚动到实际值 800ms | 属性动画 + 依次延迟 |
| M5 | 生成中（整理资料、出题） | 骨架格子 / 题号格以 1.5s 周期微光；每完成一项，对应格子由骨架变为实际状态 200ms | 骨架 + 状态切换 |
| M6 | 重排（顺延、助手改日程、拖动） | 任务块从旧位置移动到新位置 `spring.default`；被改动的项背景高亮 1s 后淡出 | `List` 动画 / 显式动画 |
| M7 | 助手弹层与卡片 | 弹层上滑 `spring.default`；助手执行动作后，页面上被改的区域高亮一次，与卡片上的“撤销”对应 | `bindSheet` |
| M8 | 按下 | 按下缩到 0.97，松开回弹 `dur.press` | `stateStyles` |

### 7.3 减少动态效果

系统或设置里开启后：所有位移、缩放、抖动改为 150ms 淡入淡出；数字直接显示最终值；地图格子直接变色；骨架不闪烁。

### 7.4 触感（鸿蒙原生）

勾掉任务、答对、完成一套题时给一次轻触感；其他时候不震。

## 8. 文案与语气

| 不要 | 要 |
|---|---|
| 标题下的解释：“按考试日期排，最近的在上面” | 删掉，排序本身就说明了 |
| “这两份像是同一课件的不同版本，用哪一份？不选也行……” | “已用较新的版本 · 改” |
| “依据有限” | 删掉；需要时在二级页面写“老师没提到，按课件篇幅估计” |
| “出错了” | “资料没有读出来：文件可能加密了 · 重新上传” |
| “未学 23” | “还有 23 个知识点没学” |
| “AI 为你生成了……”“希望对你有帮助！” | 直接给内容 |
| 感叹号、表情符号 | 不用 |

- 数字用阿拉伯数字，单位与数字间不空格（“12天”“5道题”在标签里可紧凑），正文里遵循中文排版习惯。
- 按钮 2–6 个字，动词开头；完成提示用同一个动词（“开始快练”→“快练完成”）。
- 助手的语气见 03 第 9 节。

## 9. 品牌

- **名字：满格**（英文 Fullgrid）。知识点地图的格子全部点亮，就是这门课复习到位；同时是“信号满格、状态满格”的日常说法，好记、不需要解释。上架前核查商标和应用市场重名。
- **一句话**：“复习到满格。”只用在欢迎页和应用市场，不在应用内反复出现。
- **字标**：“满格”两字用 HarmonyOS Sans SC Bold，不做变形和描边。
- **图标**：2×2 的知识点地图，三格已经点亮为掌握色，第四格是不稳的琥珀色、正在变绿——“马上满格”。鸿蒙端按图标规范提供前景、背景两层；背景用白色，不用渐变。
- 不做吉祥物、不做插画体系。
