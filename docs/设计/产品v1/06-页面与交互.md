# 06 · 页面与交互

每页按同一结构写：做什么、内容、操作、状态、三端差异、助手、动效。组件和视觉见 07，接口见 08。

通用约定：

- 每页最多一个实心主按钮。
- 标题是名词，按钮是动词，动作名前后一致（按钮“开始快练”，完成提示“快练完成”）。
- 页面上不写解释性副标题。第一次遇到的新概念用一次性的引导气泡说明，关掉后不再出现。
- 可撤销的操作直接执行，底部出现撤销条（5 秒）；不可撤销的才弹确认。
- 所有列表项、卡片都有按下态；所有可点击元素的点击区域不小于 44×44。

---

## 1. 欢迎与登录

- **做什么**：让新用户在 10 秒内知道这是什么，并能马上看到东西。
- **内容**：产品名与图标；一句话（“把课件交给它，它帮你排好复习、陪你练会”）；一张知识点地图从灰到绿逐格点亮的短动画；“开始使用”（登录）；“先看看示例”。
- **登录**：见 05 第 2 节。
- **动效**：首屏的知识点地图点亮是全产品唯一的进场动画，约 1.2 秒，只播一次。

## 2. 首次引导

登录后依次两步，都可跳过，进度点显示在顶部：

1. **连接 AI**：04 第 2.1 节的三步。
2. **建第一门课**：等同于第 5 节的新建课程引导。

跳过全部 → 今天页，示例课程已在列表里，并标“示例”。

## 3. 今天

- **做什么**：回答“现在做什么”。
- **内容（自上而下）**：
  1. 日期 + 每日简报（两三句话，助手生成，可收起）。
  2. 倒计时条：每门课一个胶囊（课程色 + 名称 + 剩余天数），离考试最近的在左，考前 3 天变为强调样式。
  3. 继续：上次停在哪（任一设备），一张卡片。
  4. 今日任务：按顺序排列的任务卡（课程色条、名称、类型图标、预计时长）。顶部一个进度环（已完成 / 总数）和“今天只有……”的时间调整入口。被自动顺延的任务带一个小标记，点开说明原因。
  5. 已完成：折叠的列表。
- **操作**：点任务卡 → 开始（学习页 / 练习）；长按（手机）或悬停菜单（电脑）→ 挪到明天、跳过、去这门课；调整今天的可用时间。
- **状态**：没有课程 → 空状态“添加第一门课”（主按钮）+ 示例课程入口；今天任务全部完成 → 进度环满，一句“今天的任务完成了”+ 明天预览 + “再练一会儿”（快练）。
- **三端**：手机一列；平板左任务、右“继续 + 本周概览”；电脑左任务、中本周日程、右助手。
- **助手**：底部输入条 / 右侧面板。常用快捷指令（输入框上方的小按钮）：“今天只有 1 小时”“先复习高数”“来 5 道题”。
- **动效**：勾掉任务——勾的描边画出 → 卡片收进“已完成” → 进度环增长（07 第 7.2 节 M2）。顺延的任务出现时有一次轻微的位移提示。

## 4. 课程列表

- **内容**：每门课一张卡片：课程名、考试日期与倒计时、知识点地图缩略、准备度（百分比 + 一句话，如“重点还差 12 个没掌握”）。按考试日期排序。
- **操作**：点卡片 → 课程主页；“新建课程”；卡片菜单 → 课程设置、删除。
- **动效**：卡片点开时放大成课程主页（共享元素过渡，M1）。

## 5. 新建课程引导

一屏一问，顶部进度点，任何一步都能“稍后再说”：

1. **课程与考试日期**：课程名、考试日期（可“还不确定”）。
2. **资料**：上传 / 拖入 / 拍照，可多份；上传后立即进入下一步，整理在后台进行。
3. **老师说的重点**（可跳过）：粘贴文字或拍照；“老师说过哪些考、哪些不考、题型是什么？照原话写就行。”
4. **考试形式**（可跳过）：题型和分值；若第 3 步里提到了题型，自动预填，用户确认。
5. **每天能给这门课多少时间**：滑块，默认按日程自动分配。
6. **完成**：“正在整理，好了通知你”+ 进入课程主页（整理中状态）。

- **助手**：每一步都可以直接对助手说，例如在第 3 步“老师说第五章不考，银行家算法必考”。

## 6. 课程主页

- **做什么**：一眼看出这门课还剩多少、下一步做什么。
- **内容**：
  - 顶部：课程名、倒计时、准备度环（掌握的重点 / 全部重点）。
  - 主体：**知识点地图**，按章节分块；格子颜色是掌握度，老师强调的有描边，不考的格子虚线浅色。章节标题可点开看该章知识点列表。
  - 下一步：这门课今天的任务（同今天页的任务卡）。
  - 薄弱处：最多 3 个不稳的重点，点开进知识点页。
  - 入口：资料、老师重点与考试形式、本课练习、学情。
  - 整理中：地图区域显示骨架格子，随着整理进度逐格出现（M5）。
- **操作**：点格子 → 知识点页；右上菜单 → 课程设置（考试日期、考试形式、每天时间上限、删除课程）。
- **三端**：手机地图在上、其他纵向排列；平板地图占左 2/3、右侧下一步与薄弱处；电脑再加右侧助手。
- **助手**：“这门课我还差多少”“帮我把第三章过一遍”。
- **动效**：从结果页回来时，变化过的格子依次闪一下新颜色。

## 7. 知识点学习页

- **做什么**：把一个知识点弄懂，并当场确认懂了。
- **内容**：
  1. 标题、所属章节、掌握状态、老师重点标记（“老师说：一定会考大题”原话）。
  2. 讲解：从资料整理的讲解，分段；每段末尾有出处标记（资料名 · 页码）。
  3. 怎么考：考法（记忆 / 理解 / 计算……）和对应题型，一行。
  4. 课件原页：缩略图，点开看大图，引文高亮。
  5. 小测：2–3 道题，作答即判（单选、填空）或自评。
  6. 笔记（P1）。
- **操作**：“懂了”（标记学过，进入下一个）；AI 动作按钮组：讲简单点 · 举个例子 · 考考我 · 和……有什么区别；上一个 / 下一个知识点。
- **三端**：手机单列，原页点开为全屏查看器，左右滑切换知识点；平板与电脑左原页、右讲解与小测，出处点击时左侧跳到对应页并高亮。
- **助手**：AI 动作的结果以讲解卡出现在页面里（讲解区下方），也同步进当前课程的对话线程。
- **动效**：小测答对，对应地图格子（页头的小地图）变色（M3）。

## 8. 资料

- **列表**：每份资料：名称、类型（课件 / 作业 / 笔记 / 复习提纲 / 往年卷 / 照片）、页数、整理状态、知识点数。自动判断的结果（“已用较新的版本”“按老师复习提纲处理”）以一行小字显示，带“改”。
- **原页浏览器**：页码缩略条 + 大图 + 本页的知识点标签；从知识点页跳来时定位并高亮引文。
- **操作**：上传（文件、拖入、拍照、用手机拍）；改类型；删除（确认，说明会删掉哪些知识点和题目）。
- **状态**：整理中（进度 + 当前步骤）；部分页没读出来（列出页码，“重新上传”或“跳过”）；读取失败（原因 + 重新上传）。
- **三端**：手机列表 → 浏览器；平板与电脑左列表右浏览器。

## 9. 老师重点与考试形式

- **内容**：左“老师说的”（原话片段列表，可粘贴、拍照、语音添加）；右“对应的知识点”（每段原话对应的知识点，级别：强调 / 提及 / 不考；“可能也包括”的边界知识点虚线显示，点一下加入或移除）。下方：考试形式（题型、题量、分值、时长、开闭卷），标明依据（老师 / 往年卷 / 默认）。
- **三端**：电脑与平板左右对照；手机上下排列，点原话展开对应知识点。
- **助手**：“老师今天又说了……”直接加入；“第五章到底考不考”。

## 10. 日程

- **内容**：考试周视图——横轴日期，每天一列，任务按课程色块堆叠；考试日用醒目标记。顶部：每日可用时间设置、复习强度。
- **操作**：拖动任务到别的日期（电脑、平板）；手机上长按 → 挪到……；固定某天给某门课；“按现在的情况重排”（大多数时候不需要，系统已自动顺延）。
- **三端**：手机只显示今天和明天 + “查看整周”；平板周视图；电脑周视图 + 右侧助手。
- **动效**：拖动时任务块跟手，放下有弹簧回弹；系统重排时任务块移动到新位置（M6）。

## 11. 练习中心

- **内容**：四个入口卡片，每个带数量：
  - 快练（“5 道，按薄弱和到期挑”）
  - 到期复习（今日到期 N 道）
  - 错题本（N 道，按课程分组）
  - 模拟卷（按考试形式出一整套）
  下方：练习记录（最近的快练、复习、模拟卷，含得分和日期；行尾菜单可删除）。
- **按知识点练**：从课程主页或知识点页进入。
- **错题本**：每道错题：题干摘要、错在哪（自评或判分结果）、所属知识点；操作：再做一遍、来一道同类的、移出错题本。做对两次自动移出。
- **出题等待**：题目先出先做（02 第 3.3 节），题号格逐个亮起（M5）。

## 12. 作答

- **单题模式（手机，及快练 / 复习）**：一题一屏；顶部进度条和题号；题干、选项或输入区；底部“提交”；提交后原地展开解析和出处，掌握度变化以一行显示；“下一题”。
- **整卷模式（平板、电脑的模拟卷）**：左题号格（状态：未答 / 已答 / 核对中 / 没出成）；中间题目；右侧助手或草稿区；顶部计时（可隐藏）。
- **求助**：底部“求助”→ 提示阶梯（03 第 4 节），每级一张卡片，第 3 级前提示“将记为看过答案”。
- **自评**：主观题提交后显示评分点，逐条选“得分 / 部分 / 没得分”。
- **报错**：题目菜单 → 报错（答案错 / 解析错 / 超纲 / 题意不清 / 出处不对），报错后这题不计分并从练习中移除。
- **状态**：核对中的题可作答，标一个小标记；核对发现问题且未作答时自动替换。
- **动效**：提交后对错反馈（答对：轻微放大回弹 + 绿色；答错：短促的水平抖动 + 红色），不用全屏特效（M3）。

## 13. 结果

- **内容**：得分（从 0 滚动到实际值）；用时；掌握度变化——知识点地图片段，变化的格子依次变色（M4）；错题列表；助手复盘（两三句 + 建议的下一步，例如“把条件概率再学一遍，然后来 5 道同类题”，带按钮）。
- **操作**：回看错题、按建议开始、回到今天。

## 14. 学情

- **内容**：准备度趋势（按天的折线）；各章节掌握分布（堆叠条）；薄弱知识点列表；用时统计。手机上只显示一句结论 + 地图 + 薄弱列表。
- **助手**：“按现在的速度来得及吗”。

## 15. 助手面板

见 03。界面要点：

- 顶部：线程名（课程名或“全局”）、当前模型、对话记录、新线程。
- 消息：用户消息右对齐，助手消息左对齐、无气泡背景（像文档段落）；卡片全宽；工具调用折叠成一行灰字。
- 输入区：上下文标签、输入框、`@` `/` 提示、语音、拍照 / 附件、发送；生成中“停止”。
- 空线程：显示三四个与当前页面相关的建议问题。

## 17. 通用状态

| 状态 | 表现 |
|---|---|
| 加载 | 骨架：与真实布局同形的灰块；超过 3 秒加一行说明在做什么 |
| 空 | 一句话 + 一个主按钮，不放插画（避免模板感），可放该页的知识点地图空状态 |
| 错误 | 原因 + 下一步按钮（重试、去设置、重新上传）；不出现只有“出错了”的页面 |
| 离线 | 顶部细条“离线，显示的是缓存内容”；需要联网的按钮置灰并说明 |
| 后台任务 | 页面内进度（不弹遮罩）；离开页面后完成时发通知 |
| 撤销条 | 底部，5 秒，“已挪到明天 · 撤销” |
