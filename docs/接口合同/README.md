# 接口合同

鸿蒙端、Web 前端和后端的共同依据，包括两部分：

- **数据结构：** 仓库根目录的 `schema/`（当前 v0.2；v0.3 的改动清单见 `docs/设计/设计修订v2.md` 第 4 节）。
- **后端 API：**
  - `api-v1.md`：v1.1（多用户、今天与日程、练习体系、对话卡片、插件、事件流），新前端 `client/` 和服务端 v1 按它实现。`samples-v1/` 是由 `client/src/mock/` 生成的样例响应。
  - `api-v0.md`：v0.1，已确认，现有 `server/` 和 `web/` 使用；v1 上线后停用。

修改流程见 `AGENTS.md`「接口变更」：单独开 PR，另一端负责人确认后再实现。
