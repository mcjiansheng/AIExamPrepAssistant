# 前端 client P0

日期：2026-11-25（PST）。工作线：鸿蒙端 / 前端，含核心流程细节设计。分支：`harmony/client-p0`；相关分支 `docs/detail-design-v1`（09、10）、`contract/api-v1`（合同 v1 与样例）。

## 修改

- **细节设计**：`docs/设计/产品v1/09-核心流程细节.md` 定下各流程的状态、今日任务的计算规则、先出后核、判分与提示阶梯、掌握度与到期复习、助手的撤销与提议、默认值与阈值；`10-前端设计逻辑与交互准则.md` 定下每页回答的问题、16 条交互准则、四种断点的外壳、组件状态、动效对应、数据流与统一拦截、验证方法。
- **接口合同 v1 草案**：`docs/接口合同/api-v1.md`，样例 `samples-v1/`（38 个，由演示后端生成）。
- **新前端 `client/`**（TypeScript + React + Vite）：欢迎与登录、首次引导、今天、日程、课程列表、新建课程、课程主页（知识点地图）、知识点、资料与原页、老师重点、学情、练习中心、作答、结果、错题本、通知、我的（账号、设置、AI 模型与用量、插件、数据）。助手在手机上是底部条和弹层，平板是右侧抽屉，电脑常驻右侧。设计 token 同时生成 CSS 变量和鸿蒙 `resources`；布局原语的名字和参数对齐 ArkUI。
- **浏览器内演示后端 `client/src/mock/`**：按合同 v1 实现全部接口，并落实 09 的规则（今日任务分配与顺延、知识点状态、稳定性与到期、先出后核、提示阶梯）；规则版助手会产生改动卡、撤销和提议。数据存在 localStorage。连不上服务端时自动使用。
- **给服务端的材料**：端到端测试可以用 `E2E_API=real` 连服务端 v1；`tests/unit/fixtures.test.ts` 导出示例课程、服务商预设和插件目录，供服务端做示例数据。服务端 v1 的交接文档在 `local/交接/`。

## 实现说明

- 演示后端替换的是请求层的 transport，返回真实的 `Response`（对话是 NDJSON 流），页面代码与连服务端时完全相同；服务端的 SSE 由进程内事件总线代替。
- 写操作统一返回 `Change<T>`：按 `affects` 刷新对应区域，可撤销时显示撤销条。401 自动刷新令牌后重发；`login_required` 弹登录、`ai_required` 弹连接 AI、`needs_confirmation` 显示估算，处理完用同一个幂等键重发。
- 分栏除了看断点，还看内容区的实际宽度：电脑上助手常驻时内容区会变窄，窄了就改成上下排列。
- 走查和测试中修掉的问题：重排后撤销产生重复任务（改为按任务 id 记录）；手机上助手条挡住“懂了”（只在一级页和课程主页显示）；跨课程快练的结果页缺地图；演示账号的准备度是 100%、顺延任务挑了老师排除的知识点；协议提示显示在验证码框上；引导页因旧缓存跳回；助手线程未加载完就能点建议。
- 依赖按 11-25 确认的清单。本机 PATH 上的 npm 有文件被 iCloud 清出，安装用 DevEco Studio 自带的 npm；`node_modules` 用 `xattr` 排除同步。
