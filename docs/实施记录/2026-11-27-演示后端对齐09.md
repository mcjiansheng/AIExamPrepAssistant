# 演示后端对齐 09 规则

日期：2026-11-27（PST）。工作线：鸿蒙端 / 前端。分支：`harmony/mock-09`。

## 修改

- **同一门课先到期复习再顺延**（`client/src/mock/plan.ts`、`client/src/mock/server.ts`）：参照 `server/v1/plans.py`，调整 `sortTasks` 优先级为先按课程紧迫度降序，同课内按「到期复习（0）→ 顺延的非复习任务（1）→ 学习（2）→ 模拟卷（3）→ 错题（4）→ 快练（5）」排列，导出供 `GET /courses/{id}/home` 的 `next` 复用。
- **复习每题约 1.5 分钟**（`client/src/mock/plan.ts`、`client/src/mock/practice.ts`）：`planUser` 生成到期复习任务时改为每个到期知识点 1 题（排除 `excluded` 及当天已排复习的知识点，上限 `min(20, floor(share / 1.5))`），时长 `Math.ceil(1.5 * count)`；`createSession` 抽取 `review` 排除 `excluded` 知识点；`practiceHub` 到期复习卡片改为 `count = min(due, 20)`、`minutes = max(5, ceil(due * 1.5))`。
- **提前交卷复盘写明未答题数**（`client/src/mock/practice.ts`）：参照 `server/v1/practice.py`，在没有错题时区分「这次没有作答。」、「这次答了 N 道，另有 M 道未答。可以继续复习相关知识点。」和全答且全对的复盘文案；`kp` 练习只在全部作答且全对时省略 `review`。
- **测试与记录**（`client/tests/unit/mock.test.ts`、`README.md`、`STATE.md`）：补充覆盖上述三处 09 对齐行为的单元测试，更新 `README.md` AI 参与说明和 `STATE.md`。
