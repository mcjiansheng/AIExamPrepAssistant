# 满格

AI 备考助手。大学生期中、期末备考时，把课件、作业、笔记和老师的重点交给它：它整理出考什么、排好几门课的复习时间，陪你学懂、练会，直到知识点地图“满格”。大学生鸿蒙开发课程项目，暂不上线。

## 本期交付

1 到 2 个月，3 人。鸿蒙原生 App（ArkTS/ArkUI，试卷用 ArkWeb 渲染），后端负责资料解析和模型调用。

| 优先级 | 内容 | 交付程度 |
|---|---|---|
| P0 | 上传资料、输入老师重点、生成计划和模拟卷、答题批改 | 模拟器上完整可用（没有真机） |
| P1 | 个人跨课程知识网络（如 Java 与 C++） | 两门课可用 |
| P2 | 校内知识和教师策略（三级知识库的中间层） | 模拟数据演示，权限规则真实执行 |
| 暂缓 | 跨校共享、联网找资料、录音转写 | 报告中写设计 |

当前进度和下一步见 `STATE.md`。产品设计见 `docs/设计/产品v1/`（从 `00-总览.md` 读起；2026-11-25 起产品范围和形态以它为准：先用 Web 做蓝本，再转鸿蒙原生）；AI 流程的已定设计见 `docs/设计/设计摘要.md`。

## 本机运行

执行 `python3 server/app.py --mock-model`，打开 [127.0.0.1:8765](http://127.0.0.1:8765)。这会启动真实 HTTP 和 SQLite，模型使用离线模拟。去掉 `--mock-model` 时，服务从 `LONGCAT_API_KEY` 或 `local/api_key/` 读取配置。上传原件、数据库和模型调用用量记录保存在被忽略的 `local/data/`。

后端离线测试命令为 `python3 -m unittest discover -s server/tests`。

新前端 `client/`：`cd client && npm install && npm run dev`，打开 [127.0.0.1:5173](http://127.0.0.1:5173)。没有服务端 v1 时自动使用浏览器内的演示后端；演示账号、测试命令见 `client/README.md`。
